# Arches HE Data Transformation 1.0.0 Release Notes
-------------------------------------------------

The Historic England developers have released the Arches HE Data Transformation Arches App which contains  extensions relating to data transformation.

## Initial Highlights:

- Bulk HTML from CSV Exporter - allows the generation of bulk HTML reports (using templates relating to resource models) from the uploading of a CSV file of Resource Instance IDs to identify resources for inclusion.

## Dependencies to Note:

```
Arches:
   arches==7.6.22
```
